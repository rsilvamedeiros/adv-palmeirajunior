# Design System

## Paleta

Marinho (`#082247`) e Marfim (`#FFFDF8`) foram amostrados diretamente da logo atual — não são uma escolha nova. Petróleo, Latão e Grafite/Pergaminho completam o sistema para dar profundidade e um ponto de acento.

| Nome | Hex | Uso |
|---|---|---|
| Marinho | `#082247` | Cor-base da marca — fundos principais, headers |
| Petróleo | `#0E3B45` | Tom secundário — painéis, hover sobre Marinho |
| Latão | `#A9824C` | Acento — CTAs, links, selos (com moderação) |
| Grafite | `#2B2E33` | Texto de corpo sobre fundo claro |
| Pergaminho | `#F6F1E7` | Fundo claro principal (mais quente que branco puro) |
| Marfim | `#FFFDF8` | Texto/ícone sobre Marinho |

## Tipografia

- **Piazzolla** (serif, 400–700 + itálico) — wordmark, títulos, números de destaque.
- **Libre Franklin** (sans, 300–800) — navegação, corpo de texto, UI. Ambas gratuitas via Google Fonts (`next/font/google`).

## Logotipo

Variações em `public/assets/images/brand/`: horizontal (fundo escuro/claro), empilhada, símbolo isolado, monograma "PJ" e selo circular. A logo original (`logo.jpeg`) permanece como referência histórica; os novos SVGs substituem seu uso em produção.
